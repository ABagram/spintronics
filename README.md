# Spintronics - Digitized Edition
![Static Badge](https://img.shields.io/badge/License-CC%20BY--NC--SA%204.0-blue?style=for-the-badge&link=https%3A%2F%2Fcreativecommons.org%2Flicenses%2Fby-nc-sa%2F4.0%2F)

This repository contains a digitized version of ***Spintronics* by Upper Story Ltd.**, converted into Markdown (`.md`) and compiled PDF formats for educational use.

## Project Overview
This project was undertaken as part of an academic coursework requirement to digitize the text for accessibility and study purposes. 

* **Original Author(s):** 
    Created by Paul Boswell\
    Illustrated by Aleksandar Zolotić\
    Story by Paul Boswell and Alyssa Boswell
* **Original Work:** Spintronics
