# Spintronics - Digitized Edition
![Static Badge](https://img.shields.io/badge/License-CC%20BY--NC--SA%204.0-blue?style=for-the-badge)

This repository contains a digitized version of **Act One** and **Act Two** of **Spintronics** by **Upper Story Ltd.**, converted into editable Markdown (`.md`) and static Portable Document Format (`.pdf`) formats for educational use.
